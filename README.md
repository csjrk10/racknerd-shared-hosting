## 先分清：你要的是虚拟主机，还是 VPS？

一句话判断：只想建网站、不想碰命令行，买虚拟主机；需要 root 权限、自己装环境，那要找的是 VPS。

虚拟主机是把一台服务器切成很多份共享出租，运维归主机商管，你拿到的是一个面板，传文件、绑域名、装 WordPress 都在面板里点几下完成。VPS 则是一台完整的虚拟服务器，权限全开，代价是系统、安全、备份全要自己来，没有 Linux 基础的人上手成本不低。

麻烦在于，搜“美国虚拟主机”出来的内容里混着大量 VPS 推荐文，新手照着买，拿到手只有一个 IP 和一串 root 密码，连面板都没有——这是最常见的买错场景。

反过来，如果你看完这段发现自己确实需要 VPS，几美元一个月的入门方案也有不少（Vultr、Interserver、搬瓦工这类商家都在做），但那是另一个话题，本文只解决虚拟主机怎么选。

## 常见问题

**美国虚拟主机需要备案吗？**
不需要。备案只管服务器放在中国大陆的网站，美国机房不涉及，买完绑定域名就能上线。

**一个套餐能建几个网站？**
Basic 是 1 个，Advanced 和 Elite 都不限制建站数量，多个网站共享同一份存储和流量额度。

**国内访问速度怎么样？**
洛杉矶机房离国内不算远，但走的是普通国际线路，没有 CN2 GIA 这类回国优化，电信、联通、移动的体验会有差异，晚高峰波动属于正常。如果速度是第一优先级，这类优化线路目前更多出现在 VPS 产品上，虚拟主机里很难找到。

**网站以后想搬走方便吗？**
cPanel 之间迁移是通用操作：在旧主机生成全量备份，到新主机的 cPanel 里恢复即可。RackNerd 是否提供免费迁移协助，建议开工单直接问，各家政策不同。
